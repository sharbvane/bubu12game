# v1.5.0 · 花园逐帧冒险

基于现有 v1.4.0 工程升级，Godot 4.7.2，Android 横屏。安装包为 `release/YierBubu-Garden-v1.5.0.apk`，沿用原签名，版本代码 6。局域网协议升为 6，双方须安装同一版本；v1.4 的本机续关存档路径与格式保留。

## 动画更新

- 通过本机配置的 image2.5 批量生成 4 列 × 2 行、每组 8 个连续姿态的像素图。`资产/原画/v150` 保存源图，`资产/动画` 保存裁切后的等宽横向图条；导出 APK 时不包含源图。
- 本次接入 109 组图条、共 872 帧：角色与时装 78 组、小怪 16 组、Boss 9 组、战斗特效 6 组。每组的相邻帧轮廓变化由切图脚本检查，移动帧均有明显姿态变化。
- 一二、布布各有正面待机、行走、近战、远程、受击、闪避、倒地、建造、使用道具、技能、胜利，以及侧面和背面的待机/行走。六套时装各补正面待机与正、侧、背三向行走。
- 豆芽怪等主要小怪新增移动或攻击帧；苔壳巨蜗、蜂巢女王、月冠古树各新增移动、攻击和倒地帧。木勺挥砍、法杖发射、连弩发射、花瓣旋转、莓果命中与 Boss 震地新增逐帧特效。
- 图条按共同尺寸和脚底锚点裁切，角色转向仍使用固定脚底坐标。角色动作由模拟状态驱动；近战和远程第 4 帧分别对齐判定与发射。敌人动作使用本地短时插值减轻联机快照间的停顿，特效按本地时间逐帧播放。
- 所有玩法仍由房主权威模拟。新增视觉状态随玩家/敌人快照同步；LAN 发现、三回合十八波、Boss 结算、补给准备、建造、道具、救援与续关存档保持原流程。

## 重新生成与接入

运行 `python tools/generate_v150.py pilot`、`heroes`、`views`、`outfits_front`、`outfits_directional`、`enemies`、`enemy_attacks`、`bosses`、`boss_deaths`、`effects` 可按组生成；已存在的源图会跳过。脚本通过本机 image25 skill 调用 image2.5，项目不保存 API 凭据。生成后运行 `python tools/build_v150_animations.py`，再用 Godot 编辑器导入素材。动画入口位于 `characters/bear_visual.gd`、`enemies/enemy_visual.gd`、`scripts/arena_view.gd`。

## 检查

`python tools/build_v150_animations.py` 会核验八帧布局与相邻帧轮廓变化。`python tools/run_checks.py` 覆盖动画资源、命中帧、旧存档状态缺省值、原有单机玩法、双进程 ENet、房间发现与触控；`tests/visual_check.gd` 实际渲染并检查左右转向锚点及移动帧变化。截图在 `tests/output/v150_animation_gallery.png`。
